Import customer data

Upload a CSV export with the standard churn fields. CustomerID, Name, Email, Phone and Consent are optional contact columns. Consent defaults to No if missing.

Download CSV Template

Required columns: Gender, SeniorCitizen, Partner, Dependents, Tenure, PhoneService, InternetService, OnlineSecurity, TechSupport, StreamingTV, Contract, PaperlessBilling, PaymentMethod, MonthlyCharges, TotalCharges.

Data reality: CSV import refreshes the records you upload; it is not a live CRM feed. For persistent storage on Render, attach a persistent disk and set DATABASE_PATH to a path on that disk. Do not upload real customer personal data to a public/demo deployment without authorization.
